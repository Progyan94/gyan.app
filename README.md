## 🌌 What is this?

**Gyan's Wacky Web World** is a sprawling open-source carnival of **45+ interactive web experiences**, bizarre sandboxes, cosmic simulations, and nostalgic games. 

From **Solar System Scope-style 3D celestial orreries** and **3D atomic shell visualizers** to **troll operating systems** and **falling sand cellular automata**, this project is dedicated to bringing fun, quirkiness, and experimental creativity back to the web!

## 🎧 Features

- **📲 Progressive Web App (PWA)**: Install directly to your phone or desktop home screen with offline caching.
- **🎧 Global Procedural Lo-Fi Synth**: Built-in ambient Web Audio synthesizer generating procedurally filtered pentatonic chord soundscapes.
- **🔍 Instant Search & Tag Filter**: Filter games across `Space & Science`, `Simulation & OS`, `Troll & Chaos`, `Zen & Relaxing`, and `Puzzle & Games`.
- **⭐ Pin & Like System**: Pin your favorite games to the top and like them with persistent `localStorage`.

## 📱 Multi-Platform Apps

Thanks to **Capacitor** and **Tauri 2.0**, the entire portal is pre-configured to build across mobile and desktop via automated GitHub Actions:

- **🤖 Android**: Powered by Capacitor (`npx cap sync android`) $\to$ `.apk`
- **🪟 Windows**: Powered by Tauri 2.0 $\to$ `.msi` / `.exe`
- **🍎 macOS**: Powered by Tauri 2.0 $\to$ `.dmg` (Universal binary)
- **🐧 Linux**: Powered by Tauri 2.0 $\to$ `.AppImage` / `.deb`

Download pre-built binaries directly via the **"⬇️ Download Native App"** button on the live site!
